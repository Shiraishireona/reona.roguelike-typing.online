# ローグライクタイピング：オンライン版

`index.html` を開けば起動します。元の単一HTMLは変更していません。

オンラインランキングも使う公開版は、GitHub Pages 等の静的ホスティング上で動かしてください。`file://` で直接開いた場合、ブラウザのクロスオリジン制限によりGAS通信だけがブロックされることがあります（ゲーム本体とローカル保存は動作します）。

## GASの接続

ゲームのタイトル画面で **接続設定** を開くと、次を確認できます。

- ランキング表示名
- UID（初回起動時に自動生成・固定）
- GASをウェブアプリとしてデプロイした固定の `/exec` URL

変更できるのは表示名だけです。UID と GAS URL は `config.js` に固定され、画面および保存処理から変更できません。

### クライアントがGASに送る形式

ランキング取得は次のGETです。

```
GET {GAS_URL}?action=ranking
```

GASは、次のいずれかのJSON形式を返せます。

```json
{"ranking":[{"uid":"...","username":"プレイヤー名","highScore":123456,"maxWave":25}]}
```

または、同じ並びの配列です。

```json
[["UID", "ユーザー名", 123456, 25, "最終更新日時"]]
```

リザルト時には、次のJSONを `Content-Type: text/plain` のPOSTで送信します。GAS側では `JSON.parse(e.postData.contents)` で受け取れます。

```json
{
  "action":"submit",
  "uid":"UID",
  "username":"ユーザー名",
  "highScore":123456,
  "maxWave":25,
  "updatedAt":"2026-09-06T00:00:00.000Z"
}
```

`score`、`wave`、`userName` も同時に含めているため、既存GASで別名を使っている場合にも合わせやすくしています。GAS側ではUIDで行を見つけ、最高スコア・最高到達WAVE・最終更新日時だけを更新してください。

アクション名が異なる場合は、`config.js` の `listAction` と `submitAction` を変更してください。

## 追加内容

- ランクが1上がるごとに **ベースポイントを2PT** 付与
- HP／シールド／攻撃力／WAVE回復の恒久強化
- ゲーム中のレベルアップ能力コアを最大40%強化する「能力コア精錬」
- 解放済みのみ抽選に入る新規スタイルカード **38種**（B 9、A 9、S 6、SS 4、SSS 10）
- SS / SSSレアリティの解放・抽選対応（SSSは解放済みの場合のみ3%枠で出現）
- 無限に上げられる「無限攻撃演算」「無限防御演算」「スコア・アクセラレータ」
- レベルアップ能力コアを保留して、戦闘中の `CORE CACHE` ボタンから任意のタイミングで連続選択
- WAVEが1進むごとに獲得EXPがさらに2%ずつ増加
- 初期レベル・ブースター（最大Lv.50から出撃、初期レベル分の能力コアも保留枠へ追加）
- 難易度「エンドレス」：開始時に1体、以後は10秒ごとに1体から始まり、撃破に応じて最短2秒ごとに1〜3体が侵攻
- エンドレスの前線は3体まで。以降は控えゾーンに入り、控えからも攻撃・回復を行う
- エンドレス撃破報酬：通常 +300、シールド +600、ボス +3000 スコア（リザルトでは最高到達欄に撃破数を送信）

無限強化の必要ポイントは、10Lvごとに 1 PT 上がります。無限防御は1Lvごとに残存被ダメージを0.25%下げる乗算方式のため、無限に強化しても100%軽減には到達しません。

ブラウザのローカルストレージに、UID・累積EXP・ベースポイントの使用状況・解放カードを保存します。別ブラウザやシークレットモードでは別データになります。
