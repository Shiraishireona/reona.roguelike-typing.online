# ローグライクタイピングゲーム

## 追加内容

- ランクが1上がるごとに **ベースポイントを2PT** 付与
- HP／シールド／攻撃力／WAVE回復の恒久強化
- ゲーム中のレベルアップ能力コアを最大40%強化する「能力コア精錬」
- 解放済みのみ抽選に入る新規スタイルカード **38種**（B 9、A 9、S 6、SS 4、SSS 10）
- SS / SSSレアリティの解放・抽選対応（SSSは解放済みの場合のみ3%枠で出現）
- 無限に上げられる「無限攻撃演算」「無限防御演算」「スコア・アクセラレータ」
- レベルアップ能力コアを保留して、戦闘中の `CORE CACHE` ボタンから任意のタイミングで連続選択
- WAVEが1進むごとに獲得EXPがさらに2%ずつ増加
- 初期レベル・ブースター（最大Lv.50から出撃、初期レベル分の能力コアも保留枠へ追加）
- 難易度「エンドレス」：開始時に1体、以後は10秒ごとに1体から始まり、撃破に応じて最短2秒ごとに1〜3体が侵攻
- エンドレスの前線は3体まで。以降は控えゾーンに入り、控えからも攻撃・回復を行う
- エンドレス撃破報酬：通常 +300、シールド +600、ボス +3000 スコア（リザルトでは最高到達欄に撃破数を送信）

無限強化の必要ポイントは、10Lvごとに 1 PT 上がります。無限防御は1Lvごとに残存被ダメージを0.25%下げる乗算方式のため、無限に強化しても100%軽減には到達しません。
